## Federated Research on Antihypertenstives Maternity Emulation (FRAME) target trial

---

## About the Project

FRAME aims to use federated analysis across four UK Birth cohorts which have been mapped to the Observational Medical Outcomes Partnership (OMOP) Common Data Model (CDM).
The data will be used to emulate a target randomised controlled trial comparing labetalol (a combined alpha-beta-blocker) vs. nifedipine (a calcium channel blocker) for the treatment of hypertension in pregnancy.
Specifically, this study will: 
- validate whether a federated observational target trial emulation produces findings comparable to traditional RCTs,
- extend the evidence base by examining long-term infant outcomes, and
- evaluate whether short- and long-term outcomes vary by ethnicity.

This repository will be used to keep track of progress, provide links to publications, coding scripts used for identifying cohorts and analyses. It will also document codelists used and other useful information.
